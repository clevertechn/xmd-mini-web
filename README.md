# Black Hat XMD — WhatsApp Bot Platform

A stunning landing page for the **Black Hat XMD** WhatsApp multi-command bot platform, built by **Clever Tech Nexus**.

## About

Black Hat XMD is a powerful WhatsApp bot platform featuring:

- **200+ commands** across **21 categories** (Admin, AI, Media, Tools, Fun, Convert, Anime, Sports, Design, Religion, Movies, Stalker)
- **Multi-user bot deployment** with isolated worker instances
- **AI-powered commands** — chatbot, image generation, translation
- **Coin economy** — earn coins via referrals, spend to deploy bots
- **ClickPesa payments** — Tanzanian mobile money integration (Starter, Pro, Business plans)
- **Group management** — anti-link, anti-spam, anti-call, welcome system, badword filtering
- **Web dashboard** — live console, bot logs, settings, billing, admin analytics

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS (custom dark theme with green/gold accents)
- Lucide React icons
- Space Grotesk + Inter fonts

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
